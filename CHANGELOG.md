# Changelog

## [0.1.0](https://github.com/dnsgateway/dnsprovider/compare/v0.0.1...v0.1.0) (2026-10-17)


### ⚠ BREAKING CHANGES

* **cloudflare:** Cloudflare is no Batcher, so Apply orders its changes through Record CRUD
* Apply is a root helper over Record CRUD, or the Provider's Batcher
* **cloudflare:** Records take a RecordFilter, pushed to Cloudflare by type and name
* **providertest:** Zone Status is read only once scripted
* Zone(name) reads one Zone, ErrNotFound when the Account has none
* **cloudflare:** Zones take a ZoneFilter and carry their Hosting State
* ZoneStatus becomes the optional ZoneStatusReader, read through ZoneStatusOf
* Account replaces Nameservers on the Provider interface
